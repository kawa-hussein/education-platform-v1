# education-platform-v1

## One-click Cloudflare deployment

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/kawa-hussein/education-platform-v1/tree/main/Education_Platform_V1_Foundation)

This repository contains the Cloudflare Workers + React + D1 version under `Education_Platform_V1_Foundation`.

For the one-click deployment button to work, Cloudflare requires the source repository to be public during deployment. After deployment is complete, you can change the source repository visibility again if desired.
